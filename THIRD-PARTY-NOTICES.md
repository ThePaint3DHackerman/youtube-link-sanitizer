# Dependencies and third-party materials

This source checkout uses the Windows .NET Framework, Windows Forms,
System.Drawing, and Windows clipboard/native APIs. It contains no bundled .NET
Framework runtime, NuGet packages, or external executable dependencies.
Windows and .NET Framework are supplied separately by Microsoft under their own
terms.

The application handles YouTube URLs locally and is not affiliated with or
endorsed by YouTube, Google, Discord, or Microsoft. Names identify compatibility.

The installer icon in `installer-source/App.ico` came from the existing project
package. No separate icon license or provenance record accompanied that package;
the owner must verify its redistribution rights before a public release.
